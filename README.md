# Rodrigo Cazuza

### Designer · Front-End Developer · AI-Assisted Coder

I design and build digital experiences that sit between **visual design, front-end development, interaction design, and AI-assisted engineering**.

My work moves from brand systems, Figma concepts, and high-fidelity UI through to responsive production interfaces, motion, reusable components, and deployment. I use AI as part of the development workflow for rapid prototyping, debugging, code generation, refactoring, documentation, and design-to-code iteration — while keeping the underlying HTML, CSS, JavaScript/TypeScript, component architecture, accessibility, responsiveness, and browser behavior understandable and intentional.

Based in New York City.

[Portfolio](https://rodrigocazuza.com) · [GitHub](https://github.com/Rodrigoccazuza)

## How I work

```text
Research → Visual direction → Design system → Prototype → Build → Motion → Test → Refine → Ship
```

I like working across the boundary between design and development rather than treating them as separate disciplines. That means decisions about typography, spacing, hierarchy, interaction, responsiveness, component structure, and implementation are made as one connected system.

AI is part of that workflow, but not a replacement for understanding the code. I use it to move faster while still reviewing structure, behavior, responsiveness, maintainability, and the final user experience.
