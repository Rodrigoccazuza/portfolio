### Designer · Front-End Developer · AI-Assisted Coder

I build digital experiences at the intersection of **visual design, front-end development, interaction design, design systems, and AI-assisted engineering**.

My workflow moves from brand direction and high-fidelity UI to responsive production interfaces, reusable components, motion, debugging, optimization, and deployment. I use AI as a development collaborator for prototyping, code generation, refactoring, debugging, documentation, and design-to-code iteration — while keeping the underlying code, architecture, responsiveness, accessibility, and browser behavior intentional and understandable.
